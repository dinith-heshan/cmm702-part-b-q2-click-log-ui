# Tap Interaction Study

This project is a controlled experiment designed to measure tap interaction performance across different devices and interface conditions.

The application is deployed on **Vercel**, and all interaction data is collected and stored in **Firebase Firestore** for analysis.

---

## Live Application

[https://cmm702-part-b-q2-click-log-ui.vercel.app](https://cmm702-part-b-q2-click-log-ui.vercel.app)

---

## Experiment Flow

### 1. Device Selection

Users begin by selecting their device type.

### 2. Tapping Task

* Two tapping rounds are completed
* Each round contains up to 50 taps
* Interaction data is recorded automatically

### 3. Completion Requirement

* Participants should complete at least the first round before exiting

---

## Tech Stack

* **Frontend:** Web application (JS)
* **Database:** Firebase Firestore
* **Deployment:** Vercel

---

## Notes for Participants

* Do not refresh the page during a session
* Ensure consistent interaction for accurate results
